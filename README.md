# TSApp - Cross-Platform Messenger

TSApp is a modern, feature-rich messenger application available on Desktop (Windows/Mac/Linux), Mobile (iOS/Android), and Web platforms.

## Features

- 💬 Real-time messaging
- 👥 Group chats and direct messaging
- 🔐 End-to-end encryption
- 📱 Cross-platform synchronization
- 🎨 Customizable themes
- 📎 File sharing and media support
- 🔔 Push notifications
- 🌙 Dark mode support
- ⚡ Fast and lightweight

## Project Structure

```
TSApp/
├── web/              # Web application (React)
├── desktop/          # Desktop app (Electron)
├── mobile/           # Mobile app (React Native)
├── backend/          # Backend API (Node.js/Express)
├── docs/             # Documentation
└── README.md
```
